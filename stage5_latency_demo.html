Phương án giảm latency đã áp dụng

Tối ưu được áp dụng trong customer_agent/agent_executor.py: với câu hỏi pháp lý, Customer Agent bỏ qua vòng ReAct LLM trung gian và gọi trực tiếp discover("legal_question") rồi delegate tới Law Agent.

Lý do hợp lý: system prompt cũ đã yêu cầu Customer Agent luôn dùng delegate_to_legal_agent cho câu hỏi pháp lý substantive, nên bước để LLM quyết định delegate là dư thừa trong demo này. 

Baseline path:
Client -> Customer LLM -> Registry -> Law -> Tax + Compliance -> Law aggregate -> Customer LLM -> Client

Optimized path:
Client -> Customer direct delegate -> Registry -> Law -> Tax + Compliance -> Law aggregate -> Client
